# Polices de la charte ACTEE

- **Bitter** (titrage) : Black, ExtraBold, Bold.
- **Schibsted Grotesk** (labeur) : Medium, Bold, ExtraBold.

Fichiers issus du design system ACTEE. Les deux familles sont publiées sous licence libre SIL Open Font
License 1.1 (Google Fonts), qui autorise leur redistribution avec l'application.

Elles sont servies par l'application elle-même (`server.enableStaticServing`) plutôt que par Google Fonts :
aucune requête n'est envoyée à un service tiers, conformément aux informations « Données et confidentialité ».
Le PDF les intègre aussi.
